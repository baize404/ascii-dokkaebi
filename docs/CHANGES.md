# 2.0 新舊功能差異

## 改版前的問題紀錄（基準）

基準版本：`9ce2c1d`。改版前在這個版本上執行了現有測試：單元測試 20 項全部通過，端對端測試（桌面＋手機直式，45 項）也全部通過。截圖存在 `docs/screenshots/before/`，另外補拍了手機橫式。實際遊玩時記錄到的問題：

| # | 問題 | 影響 |
| --- | --- | --- |
| 1 | 點擊移動是直線，前面有房子或樹就停住 | 玩家常卡在障礙物後面 |
| 2 | 장승直接說出石燈順序與供品，石燈只是照抄 | 沒有推理，解謎感薄弱 |
| 3 | 도깨비的謎題是常識選擇題，和村子無關，可以亂猜 | 探索與結局脫節 |
| 4 | 任務清單一開始就全部列出、長時間蓋在畫面上 | 劇透、遮擋場景 |
| 5 | 背包只有純文字，不能查看、使用或組合 | 道具沒有意義 |
| 6 | 沒有存檔，重新整理就要重玩 | 無法分段遊玩 |
| 7 | 沒有設定、暫停、主選單 | 無法調整音量、畫質、動畫 |
| 8 | 手機沒有搖桿；橫式時對話框佔畫面近一半，蓋住背包 | 手機操作不便 |
| 9 | 對話沒有肖像、沒有歷史，選項跟著文字立刻出現 | 容易誤點 |
| 10 | 沒有地圖 | 迷路 |
| 11 | 只有幾個短音效，沒有環境音與音樂 | 沉浸感不足 |
| 12 | 點錯一盞石燈就全部熄滅 | 不必要的重複操作 |
| 13 | 只有一個結局，沒有成就與圖鑑 | 重玩價值低 |
| 14 | 陰影與草叢固定最高畫質 | 低階手機負擔大 |

## 差異總表

| 項目 | 1.x | 2.0 |
| --- | --- | --- |
| 流程 | 單一關卡，三個步驟 | 五章：開場過場 → 沉睡的村落 → 四季的石燈 → 鬼怪的遊戲 → 月亮回歸 |
| 新手引導 | 開場一行通知 | 開場過場、實際移動與互動的教學提示、開場光點指引 |
| 村落解謎 | 廚房拿東西、井拿鑰匙、開倉庫 | 字條提示 → 장독대選甕；轉三次轆轤；倉庫需要容器（廚房的葫蘆瓶）；發光腳印、被咬的부적 |
| NPC | 無 | 할머니（睡著／叫醒、給針線、指向屏風）、黑貓（隱藏事件） |
| 石燈 | 장승直接說順序 | 「照著一年的順序」＋할머니屋裡的四君子屏風＋石燈刻紋三處線索推理；刻紋位置每局隨機；點錯只熄那一盞；每盞有四季特效與音階 |
| 最終謎題 | 三題常識選擇題 | 只從玩家看過的線索抽題的觀察題＋甕遊戲（觀察）；答錯可選擇看提示 |
| 提示 | 無 | 每個謎題三段提示，越後面越具體但不說答案；使用次數計入結算 |
| 結局 | 一個 | 一般結局、真結局（歸還補好的감투）；電影式月亮回歸、村子窗戶一扇扇亮起 |
| 成就／圖鑑 | 無 | 9 項成就；13 條民俗圖鑑（真實文化與遊戲設定分開、附來源） |
| 移動 | 直線點擊移動 | A* 網格尋路＋路徑拉直；到不了會顯示紅色回饋；按方向鍵取消尋路 |
| 手機 | 點擊移動 | 虛擬搖桿＋點擊移動；右下角大互動按鈕；直式、橫式皆可；安全區域 |
| HUD | 任務清單、背包清單常駐 | 一行目前目標；日誌、背包、地圖、提示、選單按鈕；探索迷霧小地圖 |
| 背包 | 文字清單 | ASCII 圖示格子；調查、使用、組合 |
| 對話 | 名字＋文字 | ASCII 肖像與表情、詞彙註解、歷史、防誤觸鎖定、數字鍵 |
| 設定 | 音效開關 | 三條音量、ASCII／3D、字元密度、畫質（自動／低／中／高）、字體大小、鏡頭震動、減少動畫、FPS |
| 存檔 | 無 | 自動存檔（含位置、道具、線索、石燈、事件、地圖迷霧、教學進度）；版本檢查、資料驗證、損壞備份；設定、成就、圖鑑另外保存 |
| 場景 | 平地 | 山丘地形與石牆、금줄、池塘水面、屋瓦紋路、窗櫺、木廊、踏腳石、落葉、薄霧 |
| 音訊 | 幾個短音效 | 三條音軌：程式生成音樂（夜晚／도깨비／月亮三種情緒）、依位置變化的環境音、材質腳步聲 |
| 鏡頭 | 跟隨 | 縮放、遮擋時自動調整、過場鏡頭、對話拉近、可關閉的震動 |
| 測試 | 單元 20＋e2e 45 | 單元 45＋e2e 61（含不傳送的真實通關、手機橫式、存讀檔、載入失敗） |

## 保留的部分

- ASCII shader 與原始 3D 畫面切換（T 鍵或設定）。
- core／render／world／game／ui／data 的模組分工；新功能都放進對應的資料夾。
- GitHub Pages＋GitHub Actions 部署方式；沒有加入後端、登入或付費服務。
