## 4.0 — 純 3D 與垂直切片「斷橋與燈」

第三版完整保留在 `v3-ascii` 分支（標籤推送被代理擋下，改用分支備份）。

### 移除

- ASCII 執行期渲染全部刪除：AsciiPass、字元圖集、四個 shader、版面計算、物件遮罩與混合修補、鏡頭字格對齊、T 鍵、設定裡的渲染模式／字元密度／取樣／字元比例／粗細、字元預覽、ASCII 標題字、ASCII 對話肖像。打包後的程式裡沒有任何 ASCII 渲染資源（不是「設成 3D 但背景還在初始化」）。
- 舊設定（2.x 的 `ascii`、3.x 的 `renderMode`、`density`、`sampling`、`glyphShape`、`glyphWeight`）讀取時自動刪除，其他設定保留；存檔格式不受影響。

### 新增

- 純 3D 渲染器：WebGL 2、Linear 工作空間→sRGB 輸出、ACES 色調映射、柔邊陰影、畫布 MSAA；高／超高畫質用 4× 多重取樣的 HDR 離屏貼圖＋選擇性光暈（Bloom）；動態解析度（自動畫質時依幀率在階梯上移動，有遲滯與冷卻）。
- 4.0 垂直切片：鏡頭導演、互動狀態機、擋風閘門機構、記憶物件五種狀態、共用風場、程序化場景重製、開場與結局演出、暫停／日誌／設定、手機舉燈切換模式。詳見 [docs/v4/](v4/)。
- 角色新增 Fall、Recover 兩個動作；燈籠改為每格從基礎值計算火焰與光（修正累乘衰減），紗面亮度跟著火力。
- 粒子可以選柔邊（純 3D）或一般混合的煙霧（不會在光暈裡變成白色光柱）。

### 修正（4.0 規格書靜態審查列出的問題，逐項讀程式確認後修正）

| # | 問題 | 確認結果 | 修正 |
| --- | --- | --- | --- |
| 1 | 切成 3D 仍初始化 ASCII 資源 | 屬實：Renderer 建構時一律建立 AsciiPass 與圖集 | 整套刪除 |
| 2 | 3D 沒有抗鋸齒 | 屬實：`antialias: false` | MSAA；Bloom 路徑用 4× 多重取樣貼圖 |
| 3 | 舉燈走過石碑就被強制拉近 | 屬實：舉燈＋距離 < 3.6 m 自動切調查鏡頭 | 只有按 E 調查才進入 |
| 4 | 調查鏡頭與移動方向可能不一致 | 屬實：移動方向直接取鏡頭的瞬間朝向 | 移動基準以有限速率追鏡頭 |
| 5 | 開說明時遊戲沒有暫停 | 屬實：說明面板只是蓋在畫面上 | 正式暫停狀態，世界與遊玩時間都停 |
| 6 | 開場就累積時間 | 屬實：每格都加時間 | 四種時間分開，只有遊玩中累積 |
| 7 | 點擊移動投影到固定 y=0 平面 | 屬實 | 先射線檢查互動物件，再檢查實際可走的地面（含成形的記憶橋） |
| 8 | 絞盤用固定等待時間 | 屬實：`setTimeout(2100)` | 閘門由手柄實際轉的角度驅動；可以轉到一半停手 |
| 9 | 主動關靈視後掉落，提示說燈熄了 | 屬實：兩種掉落用同一句話，重生後一律當成燈熄 | 掉落原因分開，燈的狀態照實保留 |
| 10 | 通關只有測試統計 | 屬實 | 結局演出＋劇情文字，統計收進可展開區 |
| 11 | 火焰大小可能累乘衰減 | 屬實：掉落中（沒有更新角色）每格乘一次火力 | 每格從基礎值重新計算 |
| 12 | 不同 GitHub 端點拿到的鏡頭程式版本不同 | 程式沒有問題：本機與部署都是同一個提交（`ca21e70`），推測是 GitHub 不同端點的快取 | 不需修改 |

### 文化考證修正

- 4.0 規格書把終點寫成「祠堂」；但石燈多立在寺院殿堂前，所以改成「山寺小殿」，屋簷下的燈籠改成韓紙燈籠。閘門上的布條改成正確的五方色（青、赤、黃、白、黑）。來源見 [docs/v4/ART-BIBLE.md](v4/ART-BIBLE.md)。

## 3.0 — The Living Village

3.0 依照改版計畫分六個階段進行，每個階段都先測試再進入下一階段。和 2.0 相比，**規則、劇情與存檔格式相容**：2.x 的設定會自動轉換；舊存檔可以繼續玩，缺少的新欄位（門的狀態、看過的地點）用預設值補上。

### 新舊差異

| 項目 | 2.0 | 3.0 |

## 2.0 新舊功能差異

### 改版前的問題紀錄（2.0 的基準）

| # | 問題 | 影響 |
| --- | --- | --- |
| 1 | 點擊移動是直線，前面有房子或樹就停住 | 玩家常卡在障礙物後面 |
| 2 | 장승直接說出石燈順序與供品，石燈只是照抄 | 沒有推理，解謎感薄弱 |
| 3 | 도깨비的謎題是常識選擇題，和村子無關，可以亂猜 | 探索與結局脫節 |

| 5 | 背包只有純文字，不能查看、使用或組合 | 道具沒有意義 |
| 6 | 沒有存檔，重新整理就要重玩 | 無法分段遊玩 |
| 7 | 沒有設定、暫停、主選單 | 無法調整音量、畫質、動畫 |
| 8 | 手機沒有搖桿；橫式時對話框佔畫面近一半，蓋住背包 | 手機操作不便 |
| 9 | 對話沒有肖像、沒有歷史，選項跟著文字立刻出現 | 容易誤點 |
| 10 | 沒有地圖 | 迷路 |
| 11 | 只有幾個短音效，沒有環境音與音樂 | 沉浸感不足 |
| 12 | 點錯一盞石燈就全部熄滅 | 不必要的重複操作 |
| 13 | 只有一個結局，沒有成就與圖鑑 | 重玩價值低 |
