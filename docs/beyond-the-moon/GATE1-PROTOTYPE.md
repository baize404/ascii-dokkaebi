# Gate 1：玩法原型「斷橋與燈」

- **試玩**：https://baize404.github.io/ascii-dokkaebi/prototype.html（正式版遊戲不受影響）
- **程式**：
  - `src/proto/rules.js`：規則，純邏輯、可測試
  - `src/proto/ProtoWorld.js`：灰盒場景
  - `src/proto/main.js`：主程式
- **錄影**：`docs/media/proto-reveal-hd.mp4`、`proto-fall-hd.mp4`、`proto-gate-hd.mp4`

## 1. 要回答的問題

> 「月魂燈籠＋靈界＋風」這組可以互相組合的規則，能不能讓第一次玩的人靠觀察和推理解開謎題，而且覺得有趣？

這次**不**回答：美術品質、地圖規模、NPC、劇情。灰盒外觀是刻意的。

## 2. 代表作的一刻（目標體驗）

1. 玩家一進場，就看到斷橋缺口上有幾條淡淡的青色線條，但不知道那是什麼。
2. 他在石碑前舉起燈籠，石碑上浮現「一隻眼睛，瞳孔是新月」。
3. 他按下靈視，斷橋缺口的線條變成一座發光的橋。這時他才意識到：**一開始看到的線條，就是答案**。
4. 他走上記憶的橋，風吹過來，燈的火力條變紅，燈熄了，他掉下去。
5. 回到橋頭，他開始注意火盆的煙：煙一陣一陣被吹倒、又直直飄起來。
6. 下一次，他等煙直起來才出發，或者找到絞盤把木閘門關上。

## 3. 規則規格

每一條規則都會在不止一個地方使用。

| 規則 | 觸發 | 狀態變化 | 取消／失敗 | 重試 |
| --- | --- | --- | --- | --- |
| R1 燈火 | 一直在跑 | 火力 0～1。在峽谷裡、閘門開著時受陣風影響下降（陣風約 0.75 秒吹熄）；避風時每秒恢復 0.8 | 火力歸 0 → 熄滅，靈視跟著結束 | 到火盆按互動重新點燈（伸手、火在接觸瞬間點著） |
| R2 舉燈 | 按住 F／「舉燈」 | 右手用 IK 把燈籠舉過頭；光照距離 8 → 13 m；3.6 m 內的石碑圖案顯現，鏡頭轉成調查特寫 | 放開就放下；舉著時火更怕風（消耗 ×1.8） | — |
| R3 靈視 | Q／「靈視」，燈要亮著 | 記憶物件變成實體、可以走；人間褪成冷色；走在記憶上放慢到 1.8 m/s | 燈熄或手動關閉 → 站在記憶上的人掉下去（0.9 秒落下＋淡出），回到最近的安全點，燈是熄的 | 回到安全點立刻可以再試 |
| R4 風 | 固定 7 秒一輪 | 平靜 3.8 秒 → 預兆 0.8 秒（煙開始傾斜、風聲漸強）→ 陣風 2.4 秒 | 關上木閘門 → 峽谷沒有風，煙直直往上 | 絞盤可以再打開 |
| R5 記憶的線條 | 一直在 | 人間：記憶物件只畫青色線條字元（3D 模式是青色線框，謎題在兩種模式都能解）；靈視：實體發光 | — | — |

ASCII 在這裡是玩法的一部分（R5）：玩家在人間看到的「只有線條、沒有填色」的字元，就是記憶物件的記號。學會這條規則之後，他會開始注意場景裡其他只有線條的東西。

## 4. 關卡動線與無文字教學

```
          [祠堂]  石燈（終點）
            │
   ─────── 記憶的橋（人間斷了）─────── 峽谷 ──────── [木閘門]
            │                                         ↑ 風從東邊吹進來
   [小平台]  橋頭    火盆（煙＝風的指標）     絞盤 ─┘
  石碑 B ← 記憶木板 ← ─ ─ ─ 庭院
                         石碑 A
                         起點
```

| 階段 | 玩家做什麼 | 教學方式（先畫面、後文字） |
| --- | --- | --- |
| Teach 舉燈 | 走到石碑 A | 石碑上有微弱閃光；在旁邊停留 6 秒還沒舉燈，才出現提示 |
| Teach 靈視 | 看懂「眼睛＋新月」 | 石碑圖案；15 秒沒用靈視才出現提示 |
| Test 靈視 | 走過溝上的記憶木板，讀石碑 B | 木板的青色線條從一開始就看得到 |
| Combine 靈視＋風 | 走上記憶的橋 | 火力條變紅、出現「風」、風聲、火變小 |
| Twist 兩種解法 | 看煙抓時機，或關閘門 | 掉 2 次才提示看煙；掉 4 次才提示閘門 |

風險與報酬：

- 看準時機過橋：不用繞路，但要觀察節奏，失敗會掉下去。
- 關閘門：要多走一段到絞盤，但之後一定過得去。
- 舉燈：能看到隱藏的東西，代價是在風裡更容易熄。

## 5. 謎題設計表：峽谷的斷橋

| 欄位 | 內容 |
| --- | --- |
| 目的 | 讓玩家把「靈視」和「風」兩條規則組合起來 |
| 已知規則 | 舉燈會顯現圖案；靈視會看到記憶；記憶的橋可以走 |
| 可取得線索 | 火盆的煙（一直看得到）、風聲、燈籠的火力條；石碑 B 的兩幅畫（燈被吹熄、閘門關上） |
| 正確推理 | 燈在峽谷裡會被風吹熄 → 燈熄靈視就結束 → 要嘛等風停（看煙），要嘛擋住風（關閘門） |
| 操作 | 靈視 → 走上記憶的橋；或先轉絞盤 |
| 合法解法 | ① 關閘門後過橋（任何時間都成功）②閘門開著，在平靜開始時出發 |
| 替代解法 | 在陣風快結束時出發也可能成功（約 39% 的出發時間點不看時機也會成功；模擬測試確認） |
| 失敗回饋 | 火變小、火力條變紅、風聲 → 熄滅 → 掉落淡出 → 回到橋頭、燈是熄的 |
| 提示層級 | 掉 2 次：看煙；掉 4 次：絞盤與閘門 |
| 前置條件 | 燈亮著（火盆就在橋頭旁邊） |
| 完成後的世界變化 | 到達祠堂；點亮石燈後原型結束 |
| 可能卡關 | 不知道靈視（有石碑與提示）；燈熄了不知道去哪點（掉下去時的訊息指向火盆） |
| 無障礙替代 | 所有圖案都有文字描述（調查石碑）；風有聲音、火力條、文字三種提示；閘門解法不需要反應速度 |
| 可解性驗證 | `tests/unit/ProtoRules.test.js`：關閘門在 0～7 秒每個出發時間都成功；平靜開始出發成功；陣風中出發一定失敗；人間到不了石碑 B 與對岸 |

## 6. 怎麼判斷保留、修改或砍掉

請找 **5 位沒玩過的同學**試玩，觀察流程見 [PLAYTEST-PROTOCOL.md](PLAYTEST-PROTOCOL.md)。下表把「看到什麼」對應到「怎麼做」：

| 要觀察的行為 | 保留 | 修改 | 砍掉 |
| --- | --- | --- | --- |
| 靈視與記憶線條：試玩後問「那些青色線條是什麼？」 | ≥3/5 能說出「過去的東西／可以走的」 | 只有 1～2 人懂 → 加強線條、改教學順序 | 0 人懂，而且靈視只是被提示逼著按 |
| 舉燈 | 有人在石碑 B 前不用提示就自己舉燈 | 都要提示 → 石碑閃光更明顯 | 沒人覺得有意義 → 改成靠近自動顯現 |
| 風與時機 | ≥3/5 在掉 ≤2 次內找到任一解法 | 多數要看到「看煙」提示 → 煙或風聲更明顯 | 多數覺得掉下去不公平、想放棄 → 拿掉時機解法，只留閘門 |
| 整體 | ≥4/5 在 15 分鐘內完成；≥3/5 說想再玩一段 | 完成但不想再玩 → 問哪裡無聊 | 多數中途放棄 |

**只有通過這一關，才值得把現有的村子改成用這組規則（Gate 3 垂直切片）。**
