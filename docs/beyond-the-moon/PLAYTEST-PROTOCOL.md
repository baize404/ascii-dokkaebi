# 真人試玩流程與觀察表（Gate 1 原型）

**目的**：看第一次玩的人能不能自己發現並組合「舉燈、靈視、風」這三條規則，以及他覺不覺得有趣。

## 準備

- 對象：5 位沒玩過、也沒看過這個專案的同學。桌面與手機各半，至少 1 位不常玩遊戲。
- 網址：https://baize404.github.io/ascii-dokkaebi/prototype.html
- 每人約 15 分鐘試玩＋5 分鐘訪談。
- 觀察員只看、只記，不要提示、不要解釋。玩家問「這個怎麼用？」時，回答「你覺得呢？試試看」。
- 如果可以，請玩家邊玩邊說出自己在想什麼（放聲思考）。

## 開場只說這一句

> 「這是一個遊戲原型，外觀還很簡陋。目標寫在開頭的說明上。我不會提示你，卡住也沒關係，照你自己的想法玩就好。」

## 試玩中要記錄的時間點

| 時間點 | 記錄 |
| --- | --- |
| 第一次舉燈 | 幾分幾秒；是自己發現，還是看到提示之後 |
| 第一次看懂石碑 A 的圖 | 他說了什麼 |
| 第一次用靈視 | 幾分幾秒；自己發現／看提示 |
| 看到青色線條時的反應 | 開始前就注意到了嗎？說了什麼？ |
| 走過記憶木板到石碑 B | 有／沒有（這一步不是必要的） |
| 第一次走上記憶的橋 | 幾分幾秒；當時是平靜還是陣風 |
| 掉下去 | 次數；每次之後他做了什麼 |
| 開始注意煙或風聲 | 幾分幾秒；他說了什麼 |
| 轉絞盤 | 有／沒有；是在讀石碑 B 之前還是之後 |
| 完成 | 幾分幾秒；用哪一種方法過橋（結算畫面也會顯示） |
| 想放棄、明顯煩躁 | 時間點與原因 |
| 「哇」「原來如此」的時刻 | 時間點與當下在做什麼 |

結算畫面會顯示完成時間、第一次舉燈、第一次靈視、過橋方式、掉落次數、重新點燈次數、看到的提示，請直接抄下來。

## 結束後問這五題（照順序，不要引導）

1. 剛剛發生了什麼？用你自己的話說一遍。
2. 那些青色線條是什麼？
3. 你是怎麼過橋的？為什麼那樣做？
4. 哪一段最讓你困惑或煩躁？
5. 如果還有下一段，你想玩嗎？為什麼？

## 怎麼解讀

依 [GATE1-PROTOTYPE.md](GATE1-PROTOTYPE.md) 第 6 節的「保留／修改／砍掉」表判斷。

- 5 個人的結果只能看出明顯的問題，不能當成統計結論。
- 如果多數人卡在同一個地方，先修那裡，再找另外 3～5 個人重測同一段。
- 測試結果請寫進 `docs/playtest/human-gate1.md`，並且和 AI 模擬測試的紀錄分開。
