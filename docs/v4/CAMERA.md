# 4.0 鏡頭設計文件（Camera Director）

程式：`src/proto/CameraDirector.js`（單元測試 `tests/unit/CameraDirector.test.js`、端對端 `tests/e2e/proto.mjs camera`）。

## 原則

自由探索由玩家控制鏡頭；關鍵互動由遊戲構圖；演出結束立刻還給玩家，而且回到**玩家原本的**模式、方位、俯仰與縮放，不是預設值。整個切片只有導演能動攝影機。

## 絞盤的動作鏡頭（第一次）

鏡頭依**機構進度**而不是時間切換：進度 < 30% 拍手握把手 → 30–85% 拍繩子、滑輪與擋板降下 → 85% 以上拍峽谷與火盆的煙。第二次之後只用一個同時看得到角色與擋板的鏡頭，不重播完整演出。

## 轉場與平滑

- 所有平滑都是 `1 − e^(−rate·dt)`，和幀率無關（30 Hz 與 144 Hz 跑同一段移動，鏡頭位置差 0.001 m，自動化）。
- 轉場用 easeInOut；**被打斷時帶著原本的速度滑出**（時間常數 0.15 s），速度連續、不會頓一下（單元測試：18 m 的連續兩段轉場，相鄰兩格位移差 < 0.12 m）。
- 開場的硬切：切換前一格停在前一個鏡頭，不會往下一個鏡頭滑一格。

## 移動方向（輸入基準）

方向鍵換算成世界方向用的是「移動基準」，不是鏡頭的瞬間朝向：

- 沒按方向鍵時，基準 = 鏡頭方位。
- 按著方向鍵時，基準每秒最多轉 1.4 rad 去追鏡頭方位。

所以鏡頭在你按著前進時突然轉 180°，角色會順著轉過去，不會突然往反方向走（自動化：相鄰兩格移動方向的夾角餘弦最小 0.94）。演出期間（鎖住移動）基準不更新。

## 遮擋與地形

- 從注視點朝鏡頭打射線，對象是石碑、樹、山寺的柱子與屋脊、閘門木架（`world.occluders`，不含草和地面）。
- 被擋住：以速率 14 快速拉近到擋住處前 0.35 m（最近 1.4 m）。
- 沒擋住：先等 0.35 秒，再以速率 2.4 慢慢退回（遲滯，不會在狹窄處來回抖）；單元測試確認退回過程單調。
- 鏡頭最低在地面上方 0.45 m；峽谷與溝的位置允許鏡頭低於平台。
- **還沒做**：遮擋物淡化（目前只拉近）。這個切片的遮擋物都不大，拉近就夠；室內場景需要時再做。
