# 4.0 美術聖經（Art Bible，切片版）

## 方向

**風格化低多邊形＋電影式夜間光影。** 不追求照片級擬真。所有模型都是程式產生的（`src/proto/assets.js`），沒有外部模型或貼圖。

參考圖（使用者提供）的定位：多數是 AI 生成的皮克斯級角色渲染，或 UE5 等級的商業遊戲截圖。我們只借**構圖與光的用法**（暖色燈籠對冷色月夜、霧把深谷藏起來、地標在遠方發光），不借角色、造型或場景。其中《夢幻新誅仙》那張是商業遊戲的宣傳圖，只當氣氛參考。

**誠實的落差**：瀏覽器裡的程序化模型做不到參考圖的精度。ASCII 拿掉之後，角色的稜角、穿模和材質一覽無遺，這是 4.0 最大的美術風險（見「已知限制」）。

## 色彩

| 用途 | 顏色 | 說明 |
| --- | --- | --- |
| 夜空、霧 | `#070c17`、`#0b1424` | 冷、深，但看得見地形輪廓 |
| 月光（主光） | `#b4c8ff`，強度 1.9 | 從西北上方打下來，有陰影 |
| 天光（半球光） | 天 `#5f78b0`／地 `#232a38` | 讓暗面不全黑 |
| 燈火、火盆 | `#ffb066`、`#ff9a48` | 畫面裡唯一的暖色來源，玩家一眼就找得到 |
| 記憶（靈界） | 自發光 `#39c6d8`、光塵 `#8ff0ff` | 冷青色、半透明；**暖色的火保持原色**，不是整個畫面套藍色濾鏡 |
| HUD | 韓紙米白 `#efe6d2`、燈火金 `#f2bd68` | 風勢除了顏色也用形狀（線條數與動畫）與文字區分 |

## 材質

| 材質 | 做法 |
| --- | --- |
| 岩壁 | 平面沿法線做雜訊位移＋水平岩層，頂端長青苔（頂點色），flat shading |
| 地面 | 頂點色：草、泥、青苔斑塊、石板路附近的踩踏痕 |
| 石材（石碑、石燈） | 雜訊侵蝕邊緣；石碑表面有顆粒、裂縫、青苔、淺刻痕（Canvas 貼圖） |
| 木材 | 三種色：一般、深色、紅土色（柱子） |
| 瓦 | 曲面屋頂＋瓦溝起伏＋明暗條紋（頂點色） |
| 韓紙 | 띠살 格子窗門貼圖；結局時自發光 |
| 記憶 | 半透明自發光，依狀態改變透明度與閃爍 |
| 草 | InstancedMesh，頂點著色器依共用風場擺動（峽谷附近受陣風影響更大） |

## 文化參考（真實）與虛構的分界

| 元素 | 真實文化 | 遊戲裡的用法（虛構） | 來源 |
| --- | --- | --- | --- |
| 청사초롱（青紗燈籠） | 以青紗為身、上下緣圍紅紗的燈籠；朝鮮後期起多用於婚禮 | 主角提的「月魂燈籠」用它的外形；照出「月亮的另一面」是虛構能力 | 韓國民族文化大百科「청사초롱」 |
| 석등（石燈） | 八角石燈多立在寺院殿堂前，構成有台石、竿石、火舍石（點燈處，開火窗）、屋蓋石、寶珠 | 玩家最後點亮的石燈，按這個結構建模 | 韓國民族文化大百科「영주 부석사 무량수전 앞 석등」「부인사 석등」 |
| 寺院小殿 | — | 4.0 規格寫的是「祠堂」。但石燈常見於寺院殿堂前，所以改成寺院小殿，避免混用沒有根據的元素 | 同上 |
| 오방색（五方色） | 青、白、赤、黑、黃五正色，對應東、西、南、北、中央 | 閘門木架上的五色布條：只取顏色，用來讓玩家看見風；**沒有宣稱任何儀式意義** | 韓國研究財團《韓國服飾辭典》「오방색」（DKHC Edu） |
| 띠살문、팔작지붕、단청色（석간주、뇌록） | 韓屋常見的格子門窗與屋頂形式、彩畫用色 | 小殿的門窗、屋頂與柱樑配色（簡化） | 一般建築常識，未逐一附來源；細節需要再考證 |
| 月亮被偷、靈界、記憶之橋 | — | 全部虛構 | — |

## 資產清單（這個切片）

角色（沿用 3.x 骨架，燈籠升級）、峽谷岩壁 ×4、平台地面 ×3、石板路 ×2、岩石、赤松 ×10、草（900–3600 葉）、斷橋殘段、橋頭柱、斷繩、記憶橋板＋扶手繩、記憶木板、石碑 ×2（含顯影層）、火盆、絞盤（A 字架、捲筒、大小齒輪、棘爪、手柄）、擋風閘門（木架、滑輪、繩、擋板、五色布條）、寺院小殿（基壇、台階、柱、樑、牆、窗、開著的門、室內供桌、屋頂、韓紙燈籠 ×4）、石燈、月亮、遠山、星空、深谷薄霧、靈視光波。

## 驗收方式

重要資產都要在實際遊戲鏡頭裡看：`node tests/tools/proto-shots.mjs` 會在固定鏡頭位置拍照，錄影在 `docs/media/v4-*.mp4`。面數不是指標；看輪廓、比例、光影與一致性。

## 已知限制

- 主角仍是 3.x 的程序化骨架角色：五官、手指、布料厚度都是簡化的。近距離第三人稱看得出來。要做到參考圖那種角色，需要 Blender 建模或可合法使用的 GLB——這是會大幅增加工時的決定，留給你決定。
- 沒有 PBR 貼圖（法線、粗糙度、AO 貼圖）；材質靠頂點色與 Canvas 貼圖。
- 沒有環境光遮蔽與景深；Bloom 只在高、超高畫質開。
