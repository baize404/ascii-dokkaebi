# 玩家測試紀錄

> **這裡全部是 AI 模擬玩家（自動化黑箱測試）的紀錄，不是真人測試。** 目前沒有真人大學生試玩資料；下面沒有任何一筆是真人的回饋、評分或完成時間。

## 測試方法

模擬玩家（`tests/e2e/blackbox.mjs`）從正式標題畫面開始，只根據畫面上看得到的東西做決定：

- 看得到的：目前目標、互動提示、對話與選項文字、地圖上「看過的地點」清單、任務日誌、畫面訊息。
- 操作方式：鍵盤、滑鼠或觸控（手機用 CDP 送出真正的觸控事件推搖桿）。
- **不做的事**：不傳送、不讀座標、不呼叫 riddleAnswer／shellAnswer／carvingAt／pickAt 等測試介面、不看攻略。
- 謎題處理：先用讀過的文字推理，例如字條上的「最大的甕」、屏風上的季節題字；推不出來就試，答錯時可以選擇看提示。
- 測試框架只在結束後讀遊戲狀態，用來驗證與統計，不影響玩家的決定。

「時間」是測試環境的實際經過時間。測試環境是無頭 Chrome 加 SwiftShader 軟體繪圖，約 6–20 FPS，比真實裝置慢很多，所以時間只能互相比較，不代表真人遊玩時間。

## 從模擬測試看到的問題與處理

| 觀察 | 影響 | 處理 |
| --- | --- | --- |
| 讀了字條後，地圖上的 ◆ 標出장독대，但「看過的地點」清單裡沒有它，一位模擬玩家繞了很久都找不到 | 找路困難 | 已修正：任務地點一定列在清單裡（CHANGES.md Bug 14） |
| 互動提示「看看 屋裡」和地點名稱「屏風」對不起來 | 玩家不知道那是什麼 | 已修正：改成「看看 屋裡的屏風」（Bug 12） |
| 轉轆轤的動畫期間對話框暫時消失，玩家可以趁機打開地圖 | 介面重疊 | 已修正：對話進行中不能開地圖（Bug 11） |
| 沒看過屏風的玩家在石燈前只能用試的；四位模擬玩家都靠할머니的話或目標文字「找出石燈刻紋和季節的關係」找到屏風，或直接試出來 | 解謎需要讀文字 | 維持設計：提示與目標文字都指向屏風；試錯只熄一盞，不會卡關 |
| 四位都沒有完成隱藏的黑貓事件（真結局） | 真結局需要主動追貓 | 維持設計：真結局是隱藏事件；功能測試 desktopFull 有驗證可以達成 |
| 每位都有 1 次左右點到被금줄擋住的山丘 | 會看到「山丘被금줄攔住了」 | 符合設計：說明原因，不會無聲停下 |

## 建議的真人測試

建議找至少五位沒玩過的大學生，桌面與手機各半，記錄下面這些項目，再依影響程度與出現次數排序問題：

- 第一次找到可互動物件的時間
- 每章的完成時間
- 卡關的地方、用了幾次提示
- 走不到或誤觸的次數
- 介面擋住畫面的情況
- 看不清楚的畫面
- 有沒有完成主線，以及有沒有發現隱藏事件
